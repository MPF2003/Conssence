# Conssence
Extracting the essence of digital content.
A lightweight command-line tool for downloading videos, audio, and subtitles using **yt-dlp**.

---

## Before You Start

This application uses your browser cookies to access YouTube.

1. Install **Firefox**.
2. Sign in to your YouTube account using Firefox.

> Firefox is currently the supported browser for cookie extraction.

---

## Requirements

- Python 3.11+
- FFmpeg
- Firefox
